Nekuna is an independent game studio. We build free-to-play games
designed around three rules:

- **Easy to pick up** — anyone can start playing in seconds.
- **Fair by design** — skill and curiosity win, not wallets.
- **Play anywhere** — the same game on web, phone and TikTok.

Every title goes through the same process:
**Prototype → Playtest → Soft launch → Launch → Live**.

## What we've made

### Jelly Drop

<img src="https://nekuna.com/img/jelly-drop-icon.png" width="112" align="right" alt="Jelly Drop icon">

A relaxed physics merge game. Drop or slingshot planets around a
gravity well, merge two of a kind, and climb a 15-step chain —
Moon → Pulsar → black hole. No score: just soft-body planets,
a daily challenge, and skies and skins to collect.

**Play it now on the web** — [nekuna.com/games/jelly-drop](https://nekuna.com/games/jelly-drop/)
iOS and Android coming soon. Free to play, supported by ads and
optional in-app purchases.
